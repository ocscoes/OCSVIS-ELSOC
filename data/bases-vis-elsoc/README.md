# Descripción BBDD

## Promedios

1. db_long.RData: Base madre en formato long 
2. db_promedios_ola.RData: Base en formato long con promedios para indicadores, subdimensiones, dimensiones y áreas por ola
3. db_promedios_ola_muestra.RData: Base en formato long con promedios para indicadores, subdimensiones, dimensiones y áreas por ola y tipo de muestra
4. db_long_bivariados.RData: Base madre en formato long con variables para cruces
5. bivariados_long_promedios.RData: Bases de datos para cada variable de cruce con los promedios para indicadores, subdimensiones, dimensiones y áreas por ola


## Categóricos

1. db_categ.RData: Base madre en formato long con los indicadores, subdimensiones, dimensiones y áreas categorizados
2. db_categ_ola.RData:  Base en formato long con conteos y proporciones para indicadores, subdimensiones, dimensiones y áreas por ola
3. db_categ_ola_muestra.RData: Base en formato long con conteos y proporciones para indicadores, subdimensiones, dimensiones y áreas por ola y tipo de muestra
4. db_long_bivariados_categ.RData: Base madre en formato long categorizada con variables para cruces
5. bivariados_long_categoricos.RData: Bases de datos para cada variable de cruce con los conteos y proporciones para indicadores, subdimensiones, dimensiones y áreas por ola
