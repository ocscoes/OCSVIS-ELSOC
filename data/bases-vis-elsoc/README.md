# Descripción BBDD

## Promedios

1. db_madre.RData: Base madre en formato long que contiene variables de cohesión (indicadores, subdimensiones, dimensiones y áreas) junto con variables sociodemográficas.
2. df_long_jerarquica.RData: Base en formato long con promedios para indicadores, subdimensiones, dimensiones y áreas por ola con formato jerárquico
3. bivariados_long_promedios.RData: Bases de datos para cada variable de cruce con los promedios para indicadores, subdimensiones, dimensiones y áreas por ola 


## Categóricos

1. db_categ.RData: Base madre categorizada en formato long que contiene variables de cohesión (indicadores, subdimensiones, dimensiones y áreas) junto con variables sociodemográficas.
2. df_categ_jerarquica.RData:  Base en formato long con conteos y proporciones para indicadores, subdimensiones, dimensiones y áreas por ola con formato jerárquico
3. bivariados_long_categoricos.RData: Bases de datos para cada variable de cruce con los conteos y proporciones para indicadores, subdimensiones, dimensiones y áreas por ola con formato jerárquico
