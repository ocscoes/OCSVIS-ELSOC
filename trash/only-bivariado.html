Elige una de las pestañas disponibles para realizar el análisis:

  • Longitudinal: En este apartado se comparan los promedios de las dimensiones y subdimensiones a través de un gráfico de líneas histórico. Para proyectar los análisis, debes seleccionar un elemento a visualizar.

  • Ranking: Sigue la misma lógica que la sección mapa, pero mostrando un ranking ordenado por dimensiones y subdimensiones, para cada ola disponible.

  • Bivariado: Aquí se encuentran dos selectores entre los que encontrarás las dimensiones y subdimensiones, además de algunas variables de caracterización sociodemográficas.

Todas los indicadores, subdimensiones y dimensiones fueron construidos a partir de índices promediados.
